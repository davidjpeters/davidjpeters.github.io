Work Being Done

Local Search

Local search is a search algorithm that attempts to find the optimal (highest or lowest)
point of some function by making slight modifications to the input and comparing it
against its "neighbours". If done properly, it should find the global maximum or minimum.
Find the solution to the optimal power flow problem is computationally heavy, and a well
optimized search algorithm can help us find a close to optimal solution with less resources.

Uncertainty

It's impossible to predict exactly how much demand is going to be required for
any point in the future. We can use statistical sampling and other methods
to come up with a distribution of possible demands, and optimize our model
based on these predictions such that we have the lowest cost model based on
any changes in output that may need to be made.
